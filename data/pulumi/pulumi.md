## Overview

Pulumi is an infrastructure as code platform that allows developers to use general-purpose programming languages to define and manage cloud infrastructure.

## Features

- Infrastructure as code using familiar programming languages
- Multi-cloud support (AWS, Azure, GCP, Kubernetes, and more)
- CI/CD integration
- State management
- Policy as code
- Open source core with commercial offerings

## Pricing

- Open source edition available under Apache 2.0 license
- Commercial tiers available for teams and enterprises

## Deployment

Cloud-based SaaS with self-managed options via Pulumi CLI.
