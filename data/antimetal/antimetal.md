## Overview

Antimetal is an AI-powered autopilot for AWS cost optimization. Instead of generating recommendations that require manual review and implementation, Antimetal's AI makes purchasing decisions for Reserved Instances and Savings Plans within parameters defined by the customer. The platform represents a shift from advisory to autonomous FinOps.

## Key Features

- Fully autonomous AI that executes optimization strategies 24/7 without human approval gates
- Autonomous purchasing decisions for Reserved Instances and Savings Plans
- Real-time usage analysis to guide commitment decisions
- Guaranteed savings model - customers pay only a percentage of actual savings achieved
- Zero-integration deployment without code changes or agents
- Starts optimizing immediately upon setup

## Platform Engineering Fit

Antimetal aligns with platform engineering's focus on self-managing systems. The hands-off approach means cost optimization happens continuously without dedicating engineering resources. It is particularly effective for organizations with predictable baseline workloads where committed-use discounts deliver significant savings. The platform excels at the "Remediate" component of the 4Rs framework by taking action rather than just making recommendations.

## Pricing Model

Percentage of savings achieved - customers only pay a portion of the actual savings delivered. No upfront or fixed fees.

## Deployment

Zero-integration deployment. Cloud-based SaaS that connects to AWS accounts without code changes or agent installation.
