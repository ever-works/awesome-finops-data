## Overview

Scalr is a Terraform automation and collaboration platform for managing infrastructure as code at scale.

## Features

- Full Terraform CLI support
- OPA (Open Policy Agent) integration
- Hierarchical configuration model
- Collaboration and automation for Terraform workflows
- No SSO tax; all features included

## Pricing

- Free tier: up to 50 runs per month
- Paid tiers for higher run volumes and enterprise features

## Deployment

Cloud-based SaaS.
