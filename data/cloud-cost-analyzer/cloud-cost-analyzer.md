## Overview

Cloud Cost Analyzer is a read-only, developer-first CLI tool that scans AWS and Azure environments for cost waste.

## Features

- 92 automated cost waste checks
- Detection of idle NAT gateways, gp2 volumes, and over-provisioned instances
- Savings estimates
- Read-only access
- Developer-first CLI

## Pricing

- Free tier: up to 5,000 resources per scan on one AWS account
- Paid tiers: include resource IDs and exact remediation steps

## Deployment

Cloud-based SaaS with CLI access.
